Added `SonioxTTSService`, a WebSocket TTS service for Soniox's real-time speech generation API (`wss://tts-rt.soniox.com/tts-websocket`). Text is streamed in incrementally so audio for the first words comes back before the sentence is finished. Each Pipecat audio context maps to one Soniox stream: the first `run_tts` call for a context sends the config message, later calls only append text, `flush_audio` closes the stream with `text_end`, and an interruption cancels it. Streams whose context was finalized without a flush — by the base class's TTFB or idle timeout — are swept and cancelled when the next stream opens, so they stop being metered and the per-connection stream cap stays out of reach. Install with `pip install pipecat-ai[soniox]` — the same extra the Soniox STT service uses.
