Added `SonioxTTSService`, a WebSocket TTS service for Soniox's real-time speech generation API (`wss://tts-rt.soniox.com/tts-websocket`). Text is streamed in incrementally so audio for the first words comes back before the sentence is finished. Each Pipecat audio context maps to one Soniox stream: the first `run_tts` call for a context sends the config message, later calls only append text, `flush_audio` closes the stream with `text_end`, and an interruption cancels it. Install with `pip install pipecat-ai[soniox]` — the same extra the Soniox STT service uses.
